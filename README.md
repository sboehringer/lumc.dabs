# Design and Analysis of Biomedical Studies

R package for the course "Design and Analysis of Biomedical Studies" at the LUMC, Leiden, The Netherlands

# Install

Install package `devtools` in R.

```r
require('devtools');
install_github('sboehringer/lumc.dabs');
```

# Usage

The use of the package is explained on the course website.

# Contribute

Please file issues on [github](https://github.com/sboehringer/lumc.dabs) if you find errors or if you have suggestions. Pull requests cannot be directly merged as the package is automatically generated by package [package](https://github.com/sboehringer/package).
