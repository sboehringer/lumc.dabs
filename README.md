# Design and Analysis of Biomedical Studies

R package for the course "Design and Analysis of Biomedical Studies" at the LUMC, Leiden, The Netherlands. Academic year 2026/27.

# Install

```r
install.packages('remotes')
library('remotes')
remotes::install_github('sboehringer/lumc.dabs')
```

# Usage

The use of the package is explained on the course website.
